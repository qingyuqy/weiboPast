# weibo-export.user.js —— 微博备份导出油猴脚本

一键把**本人微博**抓取到本地（断点续传、IndexedDB 缓存），导出 **JSON** 与**可打印 HTML**，浏览器 `Ctrl+P` 即可存成 PDF。可选收藏、关注列表、一级评论，可选图片内嵌做离线导出。

## 与现有脚本的关系

- 抓取逻辑（`/statuses/mymblog` + `since_id` 全量翻页、长微博展开、评论/收藏/关注接口、IndexedDB 持久化与续传、JSON + 图片 CSV 导出）参考 [Chilfish/Weibo-archiver](https://github.com/Chilfish/Weibo-archiver)。
- 面向打印的 HTML 卡片排版、图片清晰度分级、表情转图片、保守限速与失败重试参考 [Shapooo/WeiBack](https://github.com/Shapooo/WeiBack)（Greasy Fork 上的“微博备份”）。
- 新增：暂停/停止、时间范围抓取、图片内嵌离线模式、旧→新/新→旧排序、封面统计、断点续传状态保存、Node 可测的核心逻辑。

## 安装

1. 浏览器安装 Tampermonkey（或 Violentmonkey）。
2. 新建脚本，把 [weibo-export.user.js](weibo-export.user.js) 的全部内容粘贴进去保存；或把文件拖入浏览器后按提示安装。
3. 打开并登录 [weibo.com](https://weibo.com)，页面右下角出现“📦 微博备份导出”面板。

## 使用

1. **uid**：默认自动从当前页面检测（`$CONFIG`/URL/页面状态），也可手填数字 uid 或昵称。
2. 按需勾选：含转发、长文展开、评论（每条 5/10/20 条）、收藏、关注列表、断点续传。
3. 选抓取范围：全部微博（since_id 翻页）或指定时间范围。
4. 点**开始导出**。数据逐页存入浏览器 IndexedDB，面板显示进度；中途可**暂停/停止**，下次点“开始导出”自动从断点继续。
5. 抓取完成后：
   - **打印 PDF** → 自动打开打印预览并弹出打印对话框，目标打印机选“另存为 PDF”即可直接保存（网页受浏览器安全限制无法静默写文件，这一步是必须的；Edge 记住一次后默认就是 PDF）。
   - **导出 HTML** → 下载 `.html`，之后随时浏览器打开 `Ctrl+P` 出 PDF。
   - **导出 JSON** → 全量结构化数据（`{user, posts, favorites, followings}`）。
   - **图片CSV** → 所有图片的原图链接清单，可配合下载工具批量拉取。

## 选项说明

| 选项 | 说明 |
| --- | --- |
| 间隔 | 每页请求间隔，默认 800ms；触发风控就调大 |
| 图质 | 1 小图 / 2 中图 / 3 大图·原图优先 |
| 图片模式 | 链接（文件小，打印时需联网加载图片）/ 内嵌离线（图片转 base64 内嵌，文件大、完全离线可用） |
| 头像内嵌 | 默认开启：头像下载后压缩至 160px 再内嵌为 base64（新浪图床防盗链，不开则打印 PDF 时头像 403 不显示） |
| 排序 | 旧→新（像日记）或新→旧 |
| 断点续传 | 从上次中断处继续；修改抓取选项前建议先“清空” |

## 合并 HTML 为一个 PDF

「内嵌离线」模式会把大存档拆成多个 `-part-N.html`（如 23 个）。想合成一个 PDF 时：

1. 用浏览器分别打开每个 HTML，`Ctrl+P` 选“另存为 PDF”；或直接用 `merge-pdf.ps1` 批量打印并合并（依赖 Python + pypdf，本机已装 Python 3.11 + pypdf 6）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\ai\weiboPast\merge-pdf.ps1 `
  -Path C:\Users\QingYu\Downloads -Pattern 'weibo-*.html' `
  -OutPdf C:\Users\QingYu\Downloads\weibo-merged.pdf
```

2. 脚本用无头 Edge 按文件名顺序逐个打印，再用 pypdf 合并成单个 PDF；输出路径即 `-OutPdf` 指定的文件。

合并后如需减小体积，可在打印对话框里降低缩放比例，或之后用 PDF 压缩工具处理。

## 注意事项

- 数据只存在本机浏览器里（weibo.com 域名的 IndexedDB），清缓存/换浏览器会丢失，请及时导出。
- 请求过快可能触发微博验证码；脚本有重试退避，触发后请到网页手动完成验证再继续。
- 只能导出当前账号能看到的内容；仅粉丝可见、被删除的微博抓不到。
- “内嵌离线”模式在图片很多时会生成很大的 HTML，导出慢属正常。
- 修改抓取选项（如是否含转发）后，建议先“清空”再重新抓取，避免新旧数据混杂。

## 常见问题

- **导出 HTML 报 `Invalid string length`？** 0.2.2 起已修复：不再把整份内容拼成一个超长字符串（浏览器单个字符串上限约 512MB），「内嵌离线」模式自动按每 120 条分多个 HTML 文件下载（文件名带 `-part-N`），「链接」模式每 2000 条一个文件；每个文件独立可打印。浏览器若询问“允许下载多个文件”，请选允许。
- **导出 HTML 卡住不动？** 0.2.1 起已修复：图片下载加了 15 秒超时（坏图/慢图自动回退为链接）、3 路并发下载、进度逐条刷新，导出过程加了异常捕获与“正在打包文件”提示。若仍很慢，多为“内嵌离线”模式要下载大量图片，建议：
  - 大存档用**链接**模式导出 HTML（打印时联网加载图片即可）；
  - 必须离线时，把**图质**调低（小/中），或先导出图片 CSV 用下载工具批量拉图。

- **打印 PDF 时没有“另存为 PDF”？** 在打印对话框的目标打印机里选择“另存为 PDF”；Edge 记住一次后默认就是它。
- **面板标题显示的版本号是什么？** 0.2.6 起面板标题直接显示版本（如「📦 微博备份导出 v0.2.6」），并会自动移除重复面板（扩展+油猴同时装只留一个）。看到版本号即可确认运行的是新代码。
- **本地缓存显示 0 条但之前有数据？** IndexedDB 按网址域名区分：`weibo.com` 与 `www.weibo.com` 是两套缓存。请用之前导出时相同的网址打开；若仍为 0，可能点过“清空”或浏览器清理了站点数据，重新“开始导出”即可。
- **点击“开始导出”没反应？** 0.2.5 起已修复：点击后立即显示“正在启动…”并禁用按钮；接口请求加了 20 秒超时（昵称转 uid 用 10 秒），网络挂起不会再无声卡死；任何启动异常都会显示在面板状态栏。若仍无反应，请先在 `edge://extensions` 里对本扩展点“重新加载”，再刷新微博页面（旧面板是更新前留下的）。
- **打印 PDF 时头像不显示？** 0.2.4 起已修复：新浪图床防盗链（无 Referer 返回 403），脚本抓取头像时自动加 Referer 并压缩内嵌为 base64，打印/离线均正常显示。已导出的旧 HTML 可用 `python-tools/embed-avatars.py` + `python-tools/compress-avatars.py` 事后补救。

- **点“开始导出”完全没反应（面板在、按钮能点、状态栏不变）？** 0.2.7 修复了一个面板 id 冲突：日期输入框和“开始导出”按钮曾共用 `id="wbx-start"`，`querySelector('#wbx-start')` 只会命中排在前面的日期框，导致点击监听器绑到了日期框上、真正的按钮没有任何事件。表现为“按钮点了没反应”，且“开始导出”按钮不会变灰。升级到 0.2.7 并刷新页面即可。

- **升级后仍不工作，怎么定位？** 点面板底部的**“自检”**按钮，它会把下面这些信息直接打到状态栏和浏览器控制台：
  1. uid 的各个来源（`$CONFIG.oid` / URL / `main-world.js` 写入的 dataset / `__INITIAL_STATE__.loginInfo.uid`）；
  2. 当前登录会话（`/ajax/profile/info` 是否返回 `ok`、账号昵称）；
  3. 第一页 `mymblog` 的真实返回（本页条数、`total`、`since_id`、首条微博的字段名）。

  按结果判断：
  - **登录会话失败** → 会话过期或未登录，重新登录 weibo.com；
  - **mymblog 失败** → 看错误里的 `@ /statuses/...` 与 ok 值：`-100` 多为风控/验证码，按提示手动验证；返回 HTML 则是被重定向到登录页；
  - **mymblog 成功但本页 0 条** → uid 不是本人（面板里 uid 默认取自页面 `$CONFIG.oid`，浏览别人主页时会是他人的），改成自己的数字 uid 或留空（留空会用当前登录账号）。

## 版本历史

- **0.2.7**：修复面板 `id="wbx-start"` 冲突（日期框抢占了“开始导出”按钮的绑定，点击无反应）；uid 解析增加兜底（留空时用当前登录账号，`/profile/info` 反查）；`apiGet` 增加 CSRF 头、非 JSON 响应识别、错误信息带上接口路径；全量翻页增加去重与“无新数据”保护；新增**“自检”**按钮。
- **0.2.6**：面板显示版本号，自动移除重复面板。
- **0.2.5**：修复点击无响应、增加请求超时与异常提示。
- **0.2.4**：修复打印时头像不显示（图床防盗链）。
- **0.2.2**：修复导出 HTML 的 `Invalid string length`（分卷导出）。
